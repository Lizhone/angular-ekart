**eKart – Full Stack E-Commerce Web Application**

Developed a full-stack e-commerce application using **Angular, Python Flask, and Microsoft SQL Server**, featuring dynamic product listings, REST API integration, and an interactive shopping experience. Implemented product search, stock-based filtering, discounted product listings, and detailed product views with size and color selection. Built a shopping cart with individual quantity management, automatic price calculations, and Local Storage persistence to maintain cart data across page refreshes.

**Tech Stack:** Angular | TypeScript | Python Flask | REST APIs | Microsoft SQL Server | PyODBC | HTML | CSS
